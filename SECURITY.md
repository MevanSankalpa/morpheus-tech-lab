# Security policy

## Supported versions

Only the latest release is supported: the one live at https://lab.morpheustech.net. Older
versions don't get fixes; a fix ships in a new release.

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**.

**Never report a vulnerability in a public issue**, pull request or discussion.

Please include what you found, how to reproduce it, and what it affects.
